# OorjaMan — Current Design Audit

**Status:** Phase 1 complete. This file is an audit only.  
**Date:** 14 September 2026  
**Scope:** Entire flagship monorepo. No application UI, tokens, fonts, or icons were changed.

Classification used throughout:

| Label | Meaning |
| --- | --- |
| **OBSERVED** | Directly present in code, assets, or screenshots |
| **INFERRED** | Reasonable reading of repeated patterns, not a written rule |
| **RECOMMENDED** | Proposed for a later design-system phase — **not** current brand law |

Do not treat **RECOMMENDED** items as existing OorjaMan rules.

## 0. How this product is actually built

**OBSERVED.** This is **not** a native Android XML / Jetpack Compose codebase.

| Surface | Stack |
| --- | --- |
| Customer app | Expo + Expo Router + React Native |
| Technician / partner app | Expo + Expo Router + React Native |
| Admin / vendor / support portals | React + Vite + shared `@oorjaman/web-ui` |
| Public marketing site | Next.js (`apps/oorjaman-web`) |
| Shared visual tokens | `packages/config` (`brand.ts`, `colors.ts`, `typography.ts`, `spacing.ts`) |
| Shared mobile UI | `packages/ui` |
| Shared web UI | `packages/web-ui` |
| Brand masters | `brand/source/` + `npm run brand:sync` |

There is **no** `colors.xml`, Compose `Color.kt`, or Android `themes.xml` design source. Native Android only receives Expo-generated splash, adaptive icons, and notification icons.

**Brand spelling in product:** `OorjaMan` (camelCase). Tagline: `WE CLEAN. YOU GENERATE.`

## 4. Current icon system

**OBSERVED primary family (both mobile apps):** **Ionicons via `@expo/vector-icons`**

- Default style: **outline** (`home-outline`, `calendar-outline`, `shield-checkmark-outline`, `pulse-outline`, `person-outline`, `star-outline`, `sunny-outline`, `chatbubbles-outline`)
- Filled used sparingly: `checkmark-circle`, `send`, `person` (partner badge)
- Colour: `colors.primary` active, `colors.mutedForeground` inactive
- Tab icons: Expo default size, active tint `#1f8660`
- Recurring sizes: 14, 16, 17, 18, 20, 21, 22, 24, 28, 32, 40, 48
- Onboarding: 48px outline in a 13% primary wash (`${colors.primary}22`)

**OBSERVED not used:** Lucide, Material Symbols, Font Awesome, Heroicons as a package. `react-native-svg` / Lottie are not app icon systems.

**Web:** Almost no icon library. Inline 16px stroke chevrons (`stroke-width="2"`, round caps) in admin CSS; marketing sections use **inline stroke SVGs at `strokeWidth="1.75"`** (`apps/oorjaman-web/components/marketing-sections.tsx`). Persona badges are CSS, not icons.

**Partner differentiation:** Technician launcher + splash add a **circular person badge** (white fill, `#549048` ring, `#1C4276` glyph). Same O, same UI chrome.

**INFERRED optical style:** 1.5–2px outline, rounded Ionicons geometry, light visual weight on mint canvas.

**RECOMMENDED (later):** One family for web + slides (Ionicons is awkward in PowerPoint). Do not mix Lucide into mobile while Ionicons remains the product language.

## 8. Major inconsistencies

Ranked by how much they break “this is obviously OorjaMan”.

1. **Two greens, two navies** — Logo `#549048` / `#1C4276` vs product `#1f8660` / `#0f2938`. Correct if governed; currently easy to mix wrongly (see Play feature graphic).
2. **Play feature graphic wordmark is flat navy** — “OorjaMan” as one colour, not split Oorja/Man. White tile behind the O. **Breaks the lockup rule already documented in `brand/README.md`.**
3. **Photography is yellow-uniform / hard-hat** — Strong visual, but yellow is **absent** from product tokens. Product is mint/teal; lifestyle is safety-yellow. Two emotional registers.
4. **Web CSS fallbacks are Tailwind stone/slate** — If variables fail, portals look like a generic shadcn app (`#0f172a`, `#e7e5e4`, `#2563eb` links).
5. **Status colour language splits** — Mobile: green-tinted chips with navy type. Web: pastel Tailwind success/warning/danger. Support inbox: many hardcoded ambers/slates.
6. **Button shape split** — App rounded-rect 10–12 vs marketing **pills**.
7. **No vector logo** — Raster-only mark + white-box lockup. Hurts slides, print at small sizes, and dark grounds.

## 9. What can be confidently extracted as the OorjaMan brand

These are **OBSERVED** and stable enough to become official standards later (not invented):

1. **Symbol:** Dimensional green→blue O (solar grid + leaf + ribbon). Do not redraw.
2. **Wordmark:** Split **Oorja** green / **Man** navy. Never a single flat colour on official lockups.
3. **Tagline:** `WE CLEAN. YOU GENERATE.` — uppercase, wide tracking, `#9B9B9B`.
4. **Product canvas:** Cool mint `#f6faf9`, white cards, hairline `#c5d9d4`, ink `#0f2938`, muted `#516a7b`.
5. **Interactive green:** `#1f8660` with white type — the working CTA, not the wordmark green.
6. **Typeface:** Plus Jakarta Sans 400/500/600/700.
7. **Mobile icons:** Ionicons outline, primary / muted tint.
8. **Component feel:** Spacious, few shadows, large tap targets (48–56), outline secondary buttons, pill status chips, 14px cards, 12px fields.
9. **Motion:** Fast, cubic, opacity/scale — not bounce, not particles.
10. **Persona system:** Same kit; partner = O + person badge; portals = 3px accent (green / Man navy / oorja green).
11. **Sync pipeline:** `brand/source` + `brand:sync` is the operational source of truth for rasters.
12. **Voice of UI:** Calm operational copy, sentence case headings, green kickers.
