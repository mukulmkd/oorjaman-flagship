# Iconography

**EXTRACTED:** Mobile uses **Ionicons** (`@expo/vector-icons`), mostly **outline**.

## Defaults

| Token | Value |
| --- | --- |
| Family | Ionicons |
| Style | Outline for navigation and lists |
| Fill | Only for state (`checkmark-circle`, `send`, partner `person`) |
| Active | `#1f8660` |
| Inactive | `#516a7b` |
| Default size | 24 |
| Small | 16–20 |
| Large | 40–48 |
| Stroke (inferred) | ~1.5–2px optical, round caps |

Tabs never swap to filled icons — colour only.

## Web / slides

**Not established as a library.** Admin uses 16px inline strokes (`stroke-width="2"`). Marketing uses `strokeWidth="1.75"`.

**NEW STANDARD (recommended):** keep Ionicons on apps. For web and PowerPoint, use outline icons with the same weight. Do not mix Lucide into the mobile apps.
