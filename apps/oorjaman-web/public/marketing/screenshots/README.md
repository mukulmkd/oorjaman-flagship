# App screenshots (optional)

Drop portrait PNGs/WebPs here to replace feature text on `/download`:

| File | Suggested screen |
|------|------------------|
| `booking.png` | Book / package select |
| `tracking.png` | Live visit / en route |
| `evidence.png` | Before/after or completion |

Until `showAppScreenshots` is true in `apps/oorjaman-web/lib/launch-flags.ts`, `/download` shows short feature lines instead of these frames (even if the files exist).
